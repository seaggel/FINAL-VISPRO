# Project Sistem Konseling Mahasiswa

Aplikasi ini dibuat menggunakan Visual Studio 2022 dan database MySQL (XAMPP).

## Panduan Setup Database (WAJIB)
Agar aplikasi dapat berjalan dan fitur pendaftaran tidak error, mohon ikuti langkah berikut:

1. Nyalakan **Apache** dan **MySQL** pada XAMPP Control Panel.
2. Buka browser dan akses **phpMyAdmin** (`localhost/phpmyadmin`).
3. Buat database baru dengan nama: **sistem_konseling_mahasiswa**
4. Klik database tersebut, lalu pilih menu **Import** di bagian atas.
5. Pilih file `konseling_mahasiswa.sql` yang berada di dalam folder **database** di project ini.
6. Klik tombol **Import/Go** di bagian bawah.

## Cara Menjalankan Aplikasi
1. Buka file `CrossPlatformApp.sln` menggunakan Visual Studio 2022.
2. Tekan tombol **Start** atau **F5**.
